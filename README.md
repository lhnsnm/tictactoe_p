# 🎮 Tic Tac Toe (Python)

A simple command-line Tic Tac Toe game built in Python.  
This project focuses on practicing core programming fundamentals like loops, conditionals, game loops, and input validation.

## 🚀 Features

- Two-player mode (X vs O)
- Clean turn-based game loop
- Input validation (prevents invalid moves)
- Win detection (rows, columns, diagonals)
- Draw detection
- Simple, readable terminal interface

## ▶️ How to Run

Make sure you have Python 3 installed.

Clone the repository:

```bash
git clone 
cd tictactoe
````

Run the game:

```bash
python tictactoe.py
```

## 🎯 How to Play

* The board positions are numbered **1–9**
* Players take turns choosing a position
* First player to align 3 marks in a row wins
* If all spaces fill with no winner → it's a draw

### Board Layout

```
1 | 2 | 3
---------
4 | 5 | 6
---------
7 | 8 | 9
```
